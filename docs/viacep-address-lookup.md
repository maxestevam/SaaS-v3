# Consulta de endereço por CEP

O preenchimento automático utiliza o endpoint público do ViaCEP no formato `https://viacep.com.br/ws/{CEP}/json/`.

Para o CEP de exemplo `01001000`, o serviço retorna `cep`, `logradouro`, `complemento`, `bairro`, `localidade` e `uf`, que serão associados respectivamente a CEP, rua, complemento, bairro, cidade e UF nos formulários.

Fonte: https://viacep.com.br/ws/01001000/json/
