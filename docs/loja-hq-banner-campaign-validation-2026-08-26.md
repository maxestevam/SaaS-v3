# Validação da campanha visual da Loja HQ

Foram cadastradas imagens externas em quatro categorias raiz: Moda Masculina, Moda Feminina, Calçados e Bolsas. Cada uma recebeu uma imagem para card e uma imagem de capa via URL HTTPS externa.

Foram cadastrados seis banners ativos em seis posições distintas: `top`, `after_row_1`, `after_row_2`, `after_row_3`, `middle` e `final`. Três deles aparecem na Home, incluindo o banner hero de topo. Cada banner possui uma mídia desktop e uma mídia mobile, totalizando doze URLs externas.

A Home pública exibiu o hero e os cards de banner; o navegador confirmou que as imagens de banner foram carregadas com dimensões naturais de `1600 × 480`.
